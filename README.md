# MiniBridge
MiniBridge is a simplified form of the card game *contract bridge*. It does away with bidding to focus on learning the basics. This repository contains a pdf of a minibridge rules & scoring cheat sheet that prints 4up on a single double sided page. Download in [letter](https://github.com/michal-dobrogost/minibridge/blob/main/minibridge-rules.pdf) or [a4](https://github.com/michal-dobrogost/minibridge/blob/main/minibridge-rules-a4.pdf) form.

These materials are copy of [Kitty Cooper's MiniBridge materials](https://bridgeteaching.com/downloads/?category=1) edited for clarity and printing.
